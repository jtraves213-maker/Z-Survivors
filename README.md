# Z Survivors

A pixel-art, Vampire Survivors–style roguelike set across Dragon Ball, Z and Super. Play solo, couch co-op, or online with up to four players.

A fan-made tribute. Not affiliated with the Dragon Ball rights holders. Sprite credits are on the title screen.

## Publish on GitHub Pages

1. Push this folder to a GitHub repository. `index.html` must be at the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to *Deploy from a branch*, pick your branch (usually `main`) and the `/ (root)` folder, then save.
4. After a minute the game is live at `https://<your-user>.github.io/<repo-name>/`.

The `.nojekyll` file tells GitHub to serve every file as-is.

## Playing online

1. One player opens the site and clicks **Host a room**. They get a 5-letter room code.
2. Friends open the same site, type the code and click **Join**. Up to four players fit in a room.
3. Everyone picks a fighter in the lobby, then the host presses **Start**.

The host's browser runs the match, and the other players stream the game from it. Connections are peer-to-peer. The free [PeerJS](https://peerjs.com) broker only introduces the players to each other, then game data goes directly between browsers.

Things to know:
- **Keep the host's tab visible.** Browsers slow down background tabs, which slows the game for everyone.
- **Some networks block it.** A few strict networks (some offices and schools) block peer-to-peer connections. If joining hangs on "Connecting", try another network.
- **The team stays together.** Everyone fights in one area, and the team is held within about one screen of each other.

## Controls

Online, every player uses their own keyboard and mouse:

| Action | Keyboard | Mouse | Gamepad |
|---|---|---|---|
| Move | WASD or arrow keys | Hold left button to move toward the cursor | Left stick or D-pad |
| Choose technique slot | 1–9 | Click a slot in the bar | LB / RB |
| Bond techniques (after a boss) | B | Click the Bond button | Y |
| Fuse (Goku + Vegeta) | E, Space or Enter | | A |
| Ultimate (full energy bar) | Q | Right-click | X |
| Pick a card or wish | 1, 2, 3… | Click it | D-pad + A |
| Pause | Esc or P | Pause button | Start |
| Sound on/off | M | | |

Couch co-op on one computer (1–4 players):
- **P1:** WASD, 1–9, E, B, Q.
- **P2:** arrows, numpad 1–9, Enter, numpad +, numpad . (ultimate).
- **P3:** IJKL, U/O, Y, H, N (ultimate).
- **Extra players:** gamepads take the last seats.

Energy fills as you defeat enemies; when the bar is full, your fighter's signature ultimate is ready. Capsule Corp capsules are scattered around the map (and bosses leave one behind): stand next to one for 3 seconds to open it for capsules, the odd ticket or senzu, and a good chance at a Dragon Ball. A fusion lasts 30 seconds and recharges in 2 minutes. As Gogeta, Goku's player aims and fires while Vegeta's player steers; Vegito is the other way round.

Bosses open with an intro card, and every ultimate flashes a cut-in of the fighter shouting the move. Summons now include an LR (Legendary Rare, 2%) tier, which plays the Dragon Ball intro manga before the card; Gogeta is the first LR.

## Regenerating art

The PNGs in `art/` are generated by the scripts in `tools/` (Python 3 + Pillow). The sources they read are in `src_art/`.

```bash
python tools/make_art.py
```

```bash
python tools/make_world_art.py
```

```bash
python tools/make_fighters.py
```

```bash
python tools/make_hd_art.py
```

`make_eb.py` (Extreme Butoden fighters, bosses, cut-ins and intro art) and `make_npcs.py` (Saturn, GBA, DS and mobile rips, the LR manga panels and the Super Saiyan clip) also need numpy. They copy any missing source sheet from the `DB SurvivorZ` folder next to this project.

```bash
python tools/make_eb.py
```

```bash
python tools/make_npcs.py
```

```bash
python tools/make_fx.py
```

After rebuilding any sprites, re-run the sizing pass so every fighter draws at the same height:

```bash
python tools/sizes.py
```
